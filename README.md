Lín Li — Artist Portfolio

A responsive, single-page portfolio website for Belfast-based contemporary oil painter Lín Li (李琳). Built with modern HTML, CSS, and vanilla JavaScript.

Features

Gallery & Lightbox: Filterable catalog with responsive previews, detailed metadata, and artwork captions.

Exhibition History: Chronological list of solo and group exhibitions across the UK, Europe, Asia, and the US.

Artist Statement & CV: Clean editorial typography highlighting her cross-cultural practice, with an integrated CV download.

Direct Contact: Integrated enquiry form with direct email functionality.

Project Structure

.
├── index.html        # Main HTML layout
├── style.css         # Styling, custom variables, and media queries
├── main.js          # Dynamic data rendering (artworks, CV, exhibitions)
├── images/           # Web-optimized artwork image files
└── CV/               # PDF download assets


Local Development

No build tools or node dependencies required. Simply clone the repository and open index.html in any browser:

git clone https://github.com/YOUR-USERNAME/lin-li-art.git
cd lin-li-art
